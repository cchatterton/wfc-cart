# WFC Cart 0.7.0

Released: 24 July 2026

WFC Cart 0.7.0 adds Phase 7 production-readiness hardening and validation.

## Highlights

- Executable production-readiness audit.
- Non-cacheable and size-bounded WFC REST requests.
- Trusted-proxy CIDR and spoof-resistant forwarding-chain handling.
- Multisite network and new-site lifecycle support.
- Schema-upgrade journal and repeat-upgrade validation.
- Improved checkout accessibility, localisation, and amount-change behaviour.
- Phase 7 lifecycle, proxy, cache, accessibility, and readiness contracts.

## Upgrade notes

- The option schema advances from 6 to 7.
- Existing settings and records are preserved.
- The trusted-proxy list starts empty.
- Forwarded client addresses remain ignored until an immediate proxy CIDR is
  explicitly approved.
- Run **WFC Cart → Production Readiness** after upgrade.
- Complete `docs/production-validation.md` before a production pilot.

## Release artifact

Install or update using the attached `wfc-cart.zip`. The archive contains the
top-level `wfc-cart/` plugin directory.
