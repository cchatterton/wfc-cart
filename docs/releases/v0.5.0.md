# WFC Cart 0.5.0

Released: 24 July 2026

WFC Cart 0.5.0 adds the Phase 5 Salesforce delivery pipeline.

## Highlights

- Server-to-server Salesforce OAuth client-credentials authentication.
- Fixed versioned Apex REST payload and response contracts.
- Stable transaction-key idempotency.
- Controlled Gravity Forms mapping without arbitrary Salesforce field access.
- Persistent delivery queue with bounded retries and manual recovery.
- Stripe refund, dispute, and cancellation reconciliation.
- Salesforce connection diagnostics and operational queue visibility.
- Memory-only Salesforce access tokens.

## Upgrade

The schema upgrade preserves all existing settings and records, adds Salesforce
defaults, and changes the delivery queue recurrence to every five minutes.

After upgrading:

1. Configure the External Client App and dedicated integration user.
2. Configure the fixed WFC Apex REST endpoint.
3. Save the controlled Gravity Forms mapping and required fields.
4. Run the saved-connection test.
5. Complete the sandbox delivery and reconciliation matrix in
   `docs/salesforce-setup.md`.

## Release artifact

Install or update using the attached `wfc-cart.zip`. The archive contains the
