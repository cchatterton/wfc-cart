# WFC Cart 0.8.0

Phase 8 adds enforceable release governance while keeping external production
approval with authorised reviewers.

## Added

- Five ordered production release gates for external staging, independent
  security review, independent accessibility review, production pilot, and
  final approval.
- Exact plugin-version and schema binding for release decisions.
- Current no-blocker technical audit prerequisite for staging and final
  approval.
- Dedicated release-approval capability and protected approval, rejection, and
  revocation actions.
- Independent-review attestations.
- Append-only SHA-256 hash-chained decision journal with fail-closed integrity
  validation.
- Privacy-minimised, checksummed JSON evidence export.
- Phase 8 contract tests and repeatable local/GitHub Actions release
  validation.
- Evidence handling, pilot, rollback, and segregation-of-duties guidance.

Installing 0.8.0 does not itself approve production use. The target environment
must complete and record all five release gates.
