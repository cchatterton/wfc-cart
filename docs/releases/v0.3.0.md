## WFC Cart 0.3.0

- Removed third-party cart and CRM integration code, hooks, prefixes, options,
  assets, migration tooling, and documentation from the current product.
- Replaced form designation with WFC-prefixed Gravity Forms cart and checkout
  settings.
- Retained WFC-native protected transaction, line-item, batch, and fund-code
  records.
- Simplified activation, capabilities, administration, dependencies, tests,
  and release packaging to WFC responsibilities only.
- Verified that the release package contains no removed integration modules or
  directories.

WFC Cart remains under active development. Stripe payment collection and
Salesforce delivery are not yet complete; do not enable live checkout.
