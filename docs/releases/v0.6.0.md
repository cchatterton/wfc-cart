# WFC Cart 0.6.0

Released: 24 July 2026

WFC Cart 0.6.0 adds the Phase 6 operational layer.

## Highlights

- Idempotent fixed-schema transaction line items.
- Salesforce payload schema `1.1` with bounded line items.
- Deterministic receipt records and optional email delivery.
- Bounded reports and privacy-minimised CSV exports.
- Validation-first operational metadata imports.
- Immutable transaction batches with per-currency totals.
- Dedicated operational capabilities and health checks.

## Upgrade notes

- Automatic receipt email remains disabled.
- Configure its Gravity Forms email field before enabling it.
- Confirm the Salesforce endpoint accepts payload schema `1.1`.
- Existing records are preserved and are not backfilled automatically.
- Review `docs/operations-guide.md` and `docs/deployment-rollback.md`.

## Release artifact

Install or update using the attached `wfc-cart.zip`. The archive contains the
top-level `wfc-cart/` plugin directory.
