# WFC Cart 0.9.0

Phase 9 adds configurable CRM ownership and a Gravity Forms-entry-only donor
PII boundary for WordPress CRM mode.

## Added

- Salesforce and WordPress CRM data-location modes.
- Conditional Salesforce queueing, scheduling, health, administration, and
  production readiness.
- Schema 9 mode inference for existing sites.
- Generic CRM state reporting and privacy-safe cart-entry links.
- Operational metadata PII guards and opaque import references.
- Phase 9 migration, readiness, retention, and recurring-mode contracts.

## Upgrade notes

- Sites with complete existing Salesforce Client ID and Client Secret settings
  retain Salesforce mode.
- Sites without those credentials move to WordPress mode and the Salesforce
  delivery schedule is removed.
- Known historical WFC-prefixed donor metadata copies, including Salesforce
  Contact IDs, are removed while financial and Gravity Forms records remain.
- Fresh installations default to WordPress mode.
- WordPress mode supports one-off packages only. Recurring and SetupIntent
  packages require Salesforce CRM mode in this release.
- Existing Phase 8 release approvals do not carry forward to version 0.9.0;
  rerun the readiness audit and release gates.

## Release artifact

Install or update using the attached `wfc-cart.zip`. The archive contains the
top-level `wfc-cart/` plugin directory.
